# Changelog

Newest first. The top version must match `version:` in `app/pubspec.yaml`; merging to `main` releases it (see `.github/workflows/release.yaml`).

## [0.1.0] - 2026-10-18
### Added
- Offline notes with rich text and drawings, search, undo, themes and fonts.
- Haptics, optional sounds, motion settings and a note menu.
- Optional sync engine (off until a backend is configured).
- Keep-style minimal home screen; version and changelog under Appearance > About.
